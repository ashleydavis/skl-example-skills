skl-example-skills

Example package for skl. It ships one command, hello. Claude slash-autocompletes /demo:hello when the namespace is demo.

GitHub repository

Install

You need skl on your PATH and SSH access to GitHub.

skl init
skl add ashleydavis/skl-example-skills --ns demo

Machine global: add -g to both commands. YAML-first install: skl-example-config.

After install

With namespace demo, Claude sees .claude/commands/demo/hello.md. Type /demo:hello.

Layout

commands/hello.md
